## 性能口径与限制

学生查询性能夹具有400节多人课程、500名学生、400条已有规则，可形成1000个规则身份；当前按选中学生读取少量规则，不再预加载独立页面的全部规则。旧页面渐进渲染与批量选择测试迁移为范围读取、单条保存、旧入口下线、余额/财务和布局验收；保留仍有调用契约的后台批量接口测试及教师批量控件测试，没有通过跳过失败来通过验收。

学生范围接口实测返回1条规则、549字节，冷请求5.63ms、热请求4.23ms，浏览器首次进入416.8ms。该接口与旧全量页面数据范围不同，不能把两者耗时直接当成同口径提速比例。
